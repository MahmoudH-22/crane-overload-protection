## Built / changed

  - top slow zone, encoder stall detection (→ JAM), soft bottom limit

- Flutter: `CraneTelemetry` has homed / heightMm / encoderErrors; the dashboard shows hook height and encoder status.
- Guide:
  - encoder wiring, timing diagram, mounting drawing and quantization graph
  - pin map, PCB connector, parts, options, tests T3.11–T3.15 and oral questions
  - implementation step Q (encoder), with K merged into J
- `CLAUDE.md` updated with the new sensor, pins and decisions.

## Decided
- Encoder on the drum's free end via a flexible coupler (not the pulley, which can slip).
- 600 P/R, quadrature x4 → 2400 counts per turn, 0.039 mm per count.
- Keep SoftwareSerial for now; fall back to hardware Serial if encoder errors appear in T3.14.
- Check the load cell's rated output: 1 mV/V → RG 91 Ω; 2 mV/V → RG 180 Ω.
